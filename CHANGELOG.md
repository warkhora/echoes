# Changelog

## 1.0.0 — Initial desktop shell

- Electron desktop shell and automated Windows and macOS packaging.
- Liquid Glass homepage, download page, and browser download prompt.
- Global media shortcuts and Firebase integration are planned; they are not yet implemented.
- Background audio, low-latency playback, and offline music caching are also planned. The bundled static interface can open without a network connection, but it does not currently play or cache music.
